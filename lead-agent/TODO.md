# Какво остава

Тези стъпки не могат да се направят в облачната среда, където е писан кодът: там няма достъп до Facebook, Instagram, LinkedIn, Reddit и Upwork, нито до вашия вход.

## Нужно е от вас

- [ ] `npm install`, `npm run setup`, `npm run login` на вашия компютър.
- [ ] Адресите на групите във Facebook, в които сте член → `config.yaml`, `sources.facebook.groups`.
- [ ] `npm run check` и преглед на резултата. Ако източник дава 0 публикации, а в браузъра ги има, селекторите в `src/selectors/` трябва да се поправят (пратете ми лога и HTML на една публикация).
- [ ] По желание: `ANTHROPIC_API_KEY` в `.env`.
- [ ] Автоматично стартиране (launchd или Task Scheduler, README).

## Непроверено на живо

- [ ] Селекторите за Facebook, LinkedIn и Instagram са по текущия им HTML и са тествани върху примерни страници със същата структура, не върху истинските сайтове.
- [ ] Търсенето във Facebook с филтър „най-нови“ (параметърът `filters` може да се смени).
- [ ] Instagram ограничава страниците с хаштагове за някои профили; тогава източникът ще дава 0 или ще иска вход.
- [ ] Reddit RSS от вашата мрежа (тук мрежата е затворена).
- [ ] Реално извикване на Claude API (тестовете ползват заместител).
- [ ] Известието на компютъра (`node-notifier`) на macOS и Windows.

## Възможни подобрения

- [ ] Български сайтове за обяви (OLX, Bazar): нужни са проверени селектори → `sources.forums.feeds` с `type: html`.
- [ ] Upwork: източник с RSS адреси (например от услуга, която ги генерира) или ръчен импорт.
- [ ] Отбелязване в таблото на заявка като „обработена“ (сега таблото е само за четене).
