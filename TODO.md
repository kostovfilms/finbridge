# Какво остава

## Нужно е от собственика

- [ ] Публикуване в Render (ако още не е): README → „Качване онлайн“. Около 5 минути, нужен е вход в Render с GitHub.
- [ ] Платен план с диск преди истински клиенти (Starter + диск `/data` + `DATA_DIR=/data`).
- [ ] `ANTHROPIC_API_KEY` и SMTP настройки в Render → Environment.
- [ ] Проверка на живо: регистрация, двуфакторен вход с телефон, изпращане на фактура до собствен имейл.

## Не може да се направи само с код

- [ ] Open Banking (нужен е договор с доставчик и лиценз/агрегатор).
- [ ] Изпращане по Viber (нужен е бизнес акаунт във Viber).
- [ ] Шаблон за импорт в Делта Про или Ажур (нужен е примерен файл от програмата).
- [ ] Плащане на абонамент (нужен е договор с платежен доставчик).

## Възможни подобрения

- [ ] Резервни кодове за двуфакторния вход.
- [ ] Истински PDF вместо HTML при изпращане на фактура.
- [ ] Странициране на `/api/fin/state` при десетки хиляди записа.
- [ ] Роли с различни права в екипа на кантората.
